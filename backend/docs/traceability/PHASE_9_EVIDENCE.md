Date: 2026-10-19. This ledger records locally observed results, not production certification. Full behavior and permissions for each page are in [PRODUCT_SPEC.md](../PRODUCT_SPEC.md) and the page-level action, implementation and state inventory is [PHASE_8_ACTIONS.md](PHASE_8_ACTIONS.md). The report distinguishes those gaps from passing tests.
